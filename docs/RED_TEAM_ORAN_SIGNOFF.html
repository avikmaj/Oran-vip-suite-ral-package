O-RAN VIP Suite — Red-Team of the Signoff

Author: AVIK MAJUMDAR · AVIK VIP FACTORY · adversarial audit + protocol-gap sweep · 2026-08-11
Question under test: what does 1522/1522 (now 1523/1523) NOT prove? · Every finding verified against source, file:line cited.
Bottom line. 1523/1523 proves the generated testbench is internally consistent and runs clean on Verilator: the spec→stimulus→model→checker→coverage pipeline executes end-to-end and reproducibly, each header codec's bit-layout is self-consistent, and the infrastructure (gates, adjudication, coverage merge, reporting) works. It does not prove that a real RU design is correct (there is no RTL design under test), that the model matches the authoritative O-RAN spec (requirements are DERIVED and self-checked), that coverage is adequate (bins are self-derived; covergroup % uncomputed), that the assertions check protocol behaviour (procedural counters / one vacuous SVA), or that the checkers can catch a bug they did not themselves plant (zero mutation testing; zero bugs ever found). This is a VIP/model integrity result, not a DUT-signoff result.

What 1523/1523 legitimately DOES prove

• The full generate→compile→run→adjudicate→coverage→report flow executes end-to-end for all 13 components + RAL, deterministically (seed-locked) on Verilator 5.020/5.050.
• Each 64-bit header codec is bit-layout self-consistent: SV pack matches the Python golden pack, and unpack inverts pack.
• The negative path's legality function fires on injected-illegal fields (EXPECTED_FAILURE_DETECTED), and the adjudicator derives STATUS from executed log evidence, not inference.
• The RAL exercises the standard uvm_reg flow (map/adapter/predictor, front-door RW, RO write-protect) against a memory model, with 0 mismatches.
• As a reusable VIP scaffold and methodology harness, the suite is real, working engineering.

Findings — ranked by severity

BLOCKERRT-001 · There is no RTL design under test

ClaimThe "block under test" is a purely combinational pack/unpack codec — no clock, no state, no protocol behaviour. Signoff therefore cannot assert design correctness.
Evidencecomponents/<slug>/rtl/<slug>_codec.sv — 13/13 codecs contain zero clocked logic (no posedge/always_ff):
module uplane_codec (...); assign wire_hdr = uplane_pack(in_hdr); assign out_hdr = uplane_unpack(rx_wire); endmodule
What 1523 does not proveNothing about an RU/DU implementation, FSMs, timing, back-pressure, or any sequential protocol behaviour. The pass count measures a model, not a design.
Fix before signoffRe-label the deliverable as VIP + reference-model signoff, OR bind the VIP to a real RTL DUT (or a behavioural reference with injected faults) and re-run. Do not present as design signoff.

BLOCKERRT-002 · Self-referential pipeline — one source of truth feeds stimulus, DUT, checker AND coverage

Claimspec.json generates the constraint set, the codec, the is_legal/first_violation checker, and the coverage bins. Positive-pass is near-tautological: Z3 emits a legal header; the same spec's checker agrees.
Evidencegen/gen_stim.py py_is_legal() is described in-file as "mirror of SV is_legal"; both derive from the same spec. uplane_first_violation() encodes the identical bounds the solver was given.
What 1523 does not proveIndependence of stimulus and checking. A conformant generator and a conformant checker built from the same text cannot disagree except on an implementation typo — so agreement is expected, not evidence of correctness.
Fix before signoffIntroduce an independent golden (different author/derivation, or the authoritative spec's own vectors) so the checker is not a restatement of the generator.

HIGHRT-003 · Checker sensitivity is unproven — zero mutation testing, zero bugs ever caught

ClaimThe testbench has never caught a defect it did not itself plant, so its power to detect a real, independent bug is unknown.
Evidencegrep -rIn "BUG-[0-9]" across regression/ lane2/ components/*/sim_out/ → empty. No BUG-### in any ledger.
What 1523 does not proveThat a 100% pass rate distinguishes a correct model from a checker that catches nothing. Both produce all-green.
Fix before signoffRun mutation / fault-injection testing: perturb the codec (swap a field slice, off-by-one a bound, drop a cross term) and require the scoreboard to FAIL. Report kill-rate as the real quality metric.

HIGHRT-004 · The strongest check is a mathematical tautology

ClaimRound-trip (unpack(pack(h)) !== h) can only fire if pack/unpack aren't inverses — it validates the TB's own bit-slicing. Pack-vs-golden compares two implementations of the same layout.
Evidencetb/uplane_tb_top.sv: m_wire=pack(m_in); m_out=unpack(m_wire); if(m_out!==m_in) ROUNDTRIP err; if(m_wire!==r_gold) PACK err. Golden r_gold is the Python pack of the same fields.
What 1523 does not proveAny protocol-semantic property (field meaning, ordering, timing). It proves the layout is invertible and two encoders agree.
Fix before signoffAdd checks against spec-sourced expected values (decode known-good captures / vendor vectors), not against the suite's own encoder.

HIGHRT-005 · "Assertions" are procedural counters; the only concurrent SVA is vacuous

ClaimLane-1 SVA_EXERCISED,... is a count of function calls, not temporal SVA. The one real concurrent-SVA interface (ecpri_if.sv) is transaction-decoupled, so valid never asserts and the properties are vacuous.
Evidencetb/*_tb_top.sv: SVA_EXERCISED,legality=%0d,roundtrip=%0d,pack=%0d printed from m_ex_* counters. ecpri_if.sv properties gate on valid; driver publishes to the analysis port and never drives vif (see VCS_PORTABILITY_NOTES).
What 1523 does not proveThat any temporal/ordering/handshake invariant was actually evaluated. Vacuous assertions pass unconditionally.
Fix before signoffWire the interface (NBA @posedge pattern already documented), add a cover per property and fail on vacuity, and add monotonic-seq_id stimulus so p_seq_inc is non-vacuous.

MEDRT-006 · Coverage measures the generator hitting its own bins

Claim100% functional is over bins the same spec.json defined; it proves the generator reached its own targets, not that the protocol space is adequately sampled. Native covergroup % was never computed on Verilator.
Evidencesuite_regression_full.json: func_holes total = 0 over self-derived COV-### bins. lane2b_report.json: "Verilator get_coverage not collected"; get_coverage()=0.
What 1523 does not proveCoverage adequacy (are the bins the right ones?), cross-coverage depth, or the true covergroup number.
Fix before signoffHave coverage bins reviewed against the authoritative spec by someone other than the bin author; compute real covergroup % on VCS/Questa/Xcelium.

MEDRT-007 · Code-coverage denominator is trivial (~15 lines); toggle ~44–61%

Claim100% statement/branch is over ~15 lines of combinational codec per component — a denominator small enough that 100% carries little assurance. Toggle sits at ~44–61%.
Evidencecode_cov.json: line total = 15 per component; toggle e.g. cpri_eth 43.75%, uplane 60.94%.
What 1523 does not proveStructural exercise of any non-trivial logic. There is little logic to cover.
Fix before signoffState code coverage against the real DUT once bound; treat the current number as model-integrity only.

MEDRT-008 · Requirements DERIVED, authoritative spec revision unpinned

ClaimField bounds, enums and cross-constraints are DERIVED, not reconciled to a pinned O-RAN.WG4.CUS revision. Model-to-spec fidelity is unmeasured.
EvidenceGAP-ORAN-001 (open) in tracker/VRD; GATE-0 marked DERIVED.
What 1523 does not proveThat the modelled legal space equals the spec's legal space. A wrong bound would be enforced consistently by generator and checker and still show 100%.
Fix before signoffPin CUS R004-v16 (or current), diff every field/enum/cross against clause text, resolve GAP-ORAN-001.

MED–LOWRT-009 · One simulator actually ran; commercial path never compiled

ClaimAll PASS evidence is Verilator. VCS/Questa/Xcelium are NOT_RUN; the double-UVM defect (now fixed) means the native-UVM path had never compiled on a commercial sim.
Evidenceportability matrix (NOT_RUN); VCS_PORTABILITY_NOTES (double-UVM root cause, run pending).
What 1523 does not proveSimulator-independence, or that the UVM elaborates on a vendor tool.
Fix before signoffRun ./run_commercial.sh vcs all 1 on a licensed host; record real logs; close the portability row.

LOWRT-010 · Header-only scope; behavioural protocol layers excluded

ClaimTiming servo (T12/T34), beam-weight math, compression SNR, PTP servo/holdover, concatenation reassembly, per-symbol ordering are explicitly out of scope.
EvidenceFUNCTIONAL_DESIGN §5 "Out of Scope".
What 1523 does not proveAny dynamic/behavioural conformance — only static header field legality.
Fix before signoffScope the signoff statement to "protocol-header transaction level"; list behavioural layers as explicit non-goals.
